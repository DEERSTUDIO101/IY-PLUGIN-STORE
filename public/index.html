YOUR STORE, IN-GAME

Connect to Infinite Yield.

  1. Download the store plugin.Download IYPluginStore.iy ↓
  2. Place it in your executor's workspace folder.
  3. Run addplugin IYPluginStore in Infinite Yield.
  4. Set this website as the catalog:
  5. Run pluginstore to open your store.

Install downloads the file. Enable loads it into IY. Community plugins may behave differently across games and executors.
